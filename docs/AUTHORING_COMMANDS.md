# Authoring command reference

Generated by `python3 tools/make_authoring_reference.py` from the same
descriptors used by the CLI. API version 1. See [the author guide](AI_AUTHORING_GUIDE.md)
for revisions, batches, coordinates, examples and validation boundaries.

Fields marked `*` are required. The C validator checks complete candidate
projects; an operation schema alone does not prove gameplay legality.

## object.put

Create or replace one explicit definition. Supply its complete format-schema record.

Write scope: `selected collection`.

| Field | Structural constraint |
| --- | --- |
| `collection` * | `{"enum":["maps","tiles","jigsaws","people","shops","encounters","events","objectives","mechs","weapons","equipment","ammunition","presentations","images"]}` |
| `value` * | `{"type":"object"}` |
| `mode` | `{"enum":["create","replace"]}` |

```json
{
  "op": "object.put",
  "collection": "events",
  "value": {
    "id": "demo:end",
    "op": "end"
  },
  "mode": "create"
}
```
