# Classic Inner Sphere mech library — 1.0.0

Twenty-five additional chassis for the editor's **Unit Library**. Open the
library to populate them automatically, select one or more, then **Import into
game**. They are editable blueprints for custom CHI projects. Place imported
designs in starting parties, shops or encounters with Maps / events. This does
not add stock to the existing Original or Updated campaigns.

These are familiar classic designs, with several rarer selections such as
Firefly and King Crab. Faction availability and historical rarity are not
enforced. Only conventional weapons and single heat sinks are used.

## Sources and adaptations

Numeric specifications come from the [MegaMek mm-data contributors](https://github.com/MegaMek/mm-data),
pinned to commit `41c091a1318d70b3d7cdb56eaa191f84ddf25115` and checked on
2026-10-18. [sources.json](sources.json) records each source path, SHA-256,
Sarna cross-reference and rear weapon count. The adapted data retains its
[CC BY-NC-SA 4.0 licence](LICENSE.md), separately from GPL engine/tool code.
No record-sheet prose, source artwork or original DOS assets are bundled.

**VERIFIED against those records:** mass, walking/jumping MP, armour by location,
weapon types/counts, heat sink totals and installed arm actuators. Standard
internal structure is generated by tonnage. Running speed follows the engine's
existing movement rules. The catalogue passes the same C definition/project
validation used by the editor and player.

**CHI adaptations:** prices are 350 credits/ton plus 500 per weapon, and reloads
cost 3 credits/shot. Weapon damage, heat and range use the editor's existing
presets. Ammunition is divided between individual guns, preserving the source's
total shots; odd rounds go to the earliest mount. CHI does not model shared
bins or split weapon criticals. King Crab AC/20s are located in the arms, where
their barrels are, rather than the torso portion reported by the MTF weapons
summary. Rear weapons retain their torso location but use ordinary CHI targeting.
Quirks and specialist communications systems are not simulated.

## Animation defaults

The library uses **Locust** animation for Locust, Jenner, Cicada, Catapult,
Marauder, Stalker, Flea, Firefly, Cataphract, Thug and King Crab. These are the
reverse-jointed silhouettes chosen for this library; depictions vary across
editions. Other mech templates use **red Stinger**. Both are temporary
silhouettes, not model-specific artwork. The original cached Jenner is corrected
in the library without changing the original campaign record.

The original **infantry animation** is now the default for all six shipped
character templates. Previews and unit editing use the same original sprite
source as CHI character rendering. The library stores an external reference,
not copied original pixels. Import into a CHI project; selecting **Install shared
NPC/enemy infantry artwork** also removes existing overrides for those roles.
Custom games with no original dependency require a package sprite first.

Existing shipped library entries receive this default-sprite correction once.
Edited statistics, variants and owned custom sprites are preserved. Subsequent
explicit choices remain intact. Imported game projects are updated only when
you explicitly import/replace their designs.

## Reproduce the numeric catalogue

Download the 25 pinned raw URLs in `sources.json` to a local research folder
using their recorded filenames. Then run:

```sh
python3 tools/make_mech_catalogue.py --source-dir work/library-mech-research
./build/btp-project validate-content content/catalogues/mechs/units.json
```

The converter checks source hashes and does no network access. Normal library
use requires neither downloads nor these research files; the committed numeric
catalogue is sufficient. Sprite preview/play requires the user's original files.
