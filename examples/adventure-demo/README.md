# Frontier Depot

A small authored-map/event example for the CHI-dependent BtechPort player.
It includes two maps, explicit visual/collision layers, a broker stocking only
Kite, a recruit, branching dialogue, a patrol encounter and a once-only reward.
Jason starts in Rook. The sample names/statistics/dialogue are invented.

Validate with `./build/btp-project validate examples/adventure-demo`.
See [the maps/events/editor guide](../../docs/M5_MAPS_EVENTS_EDITOR.md) for play
commands, a route through the example and the format contract.

The JSON files are GPL-3.0-only. No original game assets are included; the
player must supply the original files and extracted caches. This example is
an authoring demonstration, not an independently distributable game package.
Copy it with the roster editor's New project command before making changes.
