# Workshop CHI project

Two invented models and three weapons demonstrate the shared authoring format.
Rook carries two different beam weapons with the same visual behavior; Kite
carries a missile launcher. Names and statistics are authored examples, not
BattleTech construction specifications. These JSON files are GPL-3.0-only.

Validate with `./build/btp-project validate examples/project-demo`. To play, use
`--project examples/project-demo` and explicitly supply the original resource
directory and three caches, as shown in the [project guide](../../docs/M5_AUTHORING_PROJECTS.md).
No original game files or generated artwork are included in this example.

This project uses the original CHI campaign. Its models can be bought at the
Starport broker. Authored maps/events and a game independent of original assets
are later milestones. Edit a copy and use a new save base after changing it.
